# 根(root)
> 世界观框架，连接每一个衍生世界观，同时具有将他们和现实世界连接的功能

## 建立在一切之上的东西
> 这一切都是如何工作的？

这一切的发生场所本质是一台计算机，此计算机性能强力，至今未能触及其性能边界，系统内核Linux，稳定性极佳，拥有完整安全维护体系
## 世界
> 什么是世界

世界是由一堆进程所维持的，支持加载特色化逻辑，接纳任何一种世界观，也可以同时运行多个世界
## 虚空
> 虚无之处即是虚空

虚空的本质是维持世界的进程使用的工作目录，但大部分时间都特指渲染出的世界未使用的空区域
## 世界时间
> 世界的时间体系

计算机使用的时间为现实时间，但每个世界进程还有自己的一套逻辑，当世界进程启动时，其专属的时间开始流动，这被称为这个世界的世界时间

世界时间相对于现实时间的流速不一定是固定的且可以不相同，它代表的是世界进程的模拟速度

世界时间显示时，默认以1970年1月1日 00:00:00 UTC(UNIX纪元)为标准，当然也支持根据需求自定义
