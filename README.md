# 根(root)
> 根世界观，连接每一个衍生世界观，同时具有将他们和现实世界连接的功能

## 根世界观
> 这一切都是如何工作的？

### 建立在一切之上的东西
这一切的发生场所本质是一台计算机，性能强力，至今未能触及其性能边界，系统内核Linux，稳定性极佳，拥有完整安全维护体系
### 世界
世界是由一堆进程所维持的，支持加载特色化逻辑，接纳任何一种世界观，也可以同时运行多个世界
### 虚空
虚空的本质是维持世界的进程使用的工作目录，但大部分时候都特指渲染出的世界空着的区域
