# 根(root)
> 根世界观，连接每一个衍生世界观，同时具有将他们和现实世界连接的功能

## 根世界观设定
> 这一切都是如何工作的

### 建立在一切之上的东西
世界的本质是一台计算机，性能强力，至今未有人能触及其性能边界，系统内核Linux，内置硬件和运行库齐全，各种任务都能胜任，系统稳定性极佳，拥有完整安全维护体系，启动以来从未崩溃，独立运行能力强大，内部功能使用本地端口，无外接设备，未连接网络，能与外界进行交互的硬件有限，和外界有关信息全部抹除，内部有原子钟，独立时间不与外界同步，自启动时从零时间开始计算，即**1970年1月1日 00:00:00 UTC**，启动前存在的文件则停留在此时间
### 用户
计算机总会需要一个用户来操作，这个用户就是世界的创造者(世界观编写者)，详细设定可直接查看该用户的自设：[奇迹蛋糕](https://wpqppqqy.github.io/wpqppqqy/)
### 用户账号
这和用户是不同的概念，用户属于外界且只有一个，用户账号属于系统且有多个，注意分辨
### 宇宙
宇宙是一种模拟进程，模拟精度高，宇宙的模拟数据放置在用户账号的家目录下，每个用户账号隔离，无法互相感知，支持加载特色化逻辑，作为插件放置在用户账号家目录下，因此，这个世界可以接纳任何一种世界观
### 多元宇宙
同一用户账号可以拉起多个模拟进程，这就是多元宇宙，但同一用户账号创建的多元宇宙存在于同一家目录下，也就是共享同一片虚空，虽然可以通过划分文件夹的方式分开，但还需要细度设置权限阻止宇宙互相访问
### 宇宙的进一步配置
一个宇宙在创建的时候只有虚空，需要手动添加物质，然后通过引爆等方式让宇宙诞生，接着再让宇宙自行发展，这是最简单的做法，但是如果不需要完整的宇宙，最好的做法是主动设计一个，避免不必要的内存消耗，同时还可以实现想要的效果
### 宇宙的加载逻辑
为了避免不必要的内存消耗，宇宙模拟进程实际上只会加载主要活动区域(在大部分宇宙中，这个区域一般是地球及周边地区)，未加载的区块为虚空，随着世界观内容的拓展，宇宙会随之动态扩张，在未加载的区块加载之前，会看到精密计算的背景贴图，使加载更流畅，不会有闪屏现象
### 虚空
宇宙的未使用部分，无穷无尽无边界
### 背景贴图
位于宇宙最外层，因为渲染层级不同，属于非实体，不可抵达
## 根宇宙设定
> 在介绍世界观的同时，本文档也有着承载一个宇宙的功能，而根宇宙，就是世界观中的最上级存在

### 本质
由根用户拉起的宇宙进程，数据文件放置在根用户的家目录下
### 空间构成
这个宇宙本身能渲染出来的部分就非常小，只有一间简单的方形房间，有窗和门，房间之外就是无尽的虚空，拥有昼夜更替，房间内部构造简单，类似卧室，拥有床、衣柜、文件柜(为什么会有文件柜？)、电脑、书桌等日常物件，管理者(蛋糕)居住在此
### 管理者(蛋糕)
外界操作的用户所生成的个人形象，由用户直接操控，是用户的虚拟形象，根宇宙内唯一的角色，名字简称：蛋糕，完整设定：[奇迹蛋糕](https://wpqppqqy.github.io/wpqppqqy/)，平日负责管理所有宇宙，但因为系统自动化维护措施完善，所以平时一般无需维护，大部分时间都在观察其他宇宙，偶尔还会介入其中
### 故事
> 根宇宙本身没有线性故事(也没什么可写的)，能看到的都是片段日常
